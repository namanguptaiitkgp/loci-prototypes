# Loci prototypes

Static hosting for clickable design prototypes of Loci, served by GitHub Pages at
https://namanguptaiitkgp.github.io/loci-prototypes/ (search engines are asked not to index it).

| Path | What | Added |
|---|---|---|
| `v2/` | Loci v2 — clickable screens for ages 8 to 12 (Claude Design bundled export) | 1 Oct 2026 |

## Adding a prototype
1. Export the design as a single bundled HTML file.
2. Save it as `vN/index.html` (or `<name>/index.html`), set a real `<title>`, keep `<meta name="robots" content="noindex">`.
3. Add a card to `index.html` and a row to this table, then push to `main`. Pages redeploys in about a minute.

Nothing here collects data or calls any API; the bundled pages are self-contained apart from Google Fonts.
